# Заполнение текста карточки проекта

Весь текст для Hero и информационного блока заполняется в файле
`project-content.txt`. Редактировать HTML, CSS и технический файл
`project.auto.json` для изменения этих текстов не нужно.

Файл необходимо сохранять в кодировке UTF-8.

## Структура

```text
[UA]

HERO_LEFT:
СУЧАСНА
КВАРТИРА

HERO_RIGHT:
КОНСУЛЬТАЦІЯ ДО КУПІВЛІ
ТА ПРОСТОРОВЕ ПЛАНУВАННЯ

ABOUT_LABEL:
Про проєкт

ABOUT_TITLE:
Квартира для молодої сім’ї

ABOUT_TEXT:
Перший абзац опису.

Другий абзац опису.

META:
Локація | Україна
Тип об’єкта | Квартира
Площа | 93,18 м²


[EN]

HERO_LEFT:
MODERN
APARTMENT

HERO_RIGHT:
PRE-PURCHASE CONSULTATION
AND SPACE PLANNING

ABOUT_LABEL:
About the project

ABOUT_TITLE:
Apartment for a young family

ABOUT_TEXT:
First description paragraph.

Second description paragraph.

META:
Location | Ukraine
Object type | Apartment
Area | 93.18 m²
```

## Правила заполнения

- `[UA]` содержит украинскую версию, `[EN]` — английскую.
- `HERO_LEFT` и `HERO_RIGHT` допускают не более двух непустых строк.
- Пустая строка в `ABOUT_TEXT` начинает новый абзац.
- В `META` каждая строка создаёт отдельную характеристику.
- Название и значение характеристики разделяются символом `|`.
- Порядок характеристик в украинской и английской версиях должен совпадать.
- Английские поля можно временно оставить пустыми. Тогда английская страница
  использует украинский текст.
- Не следует переименовывать заголовки полей или добавлять произвольные поля.

Оформление, размеры текста, отступы, колонки и декоративные элементы остаются
в общем шаблоне и не зависят от содержания файла.

Генератор проверяет структуру и при ошибке сообщает проблемное поле или строку.
