# Шаблон автоматической карточки проекта

1. Скопируйте эту папку в `assets/projects/`.
2. Переименуйте её, например в `project-interior-apartment-005`.
3. Заполните `project-description.txt` в кодировке UTF-8. Это основной пользовательский файл проекта.
4. Оставьте `STATUS: draft`, пока проект не готов к публикации.
5. Файл `project-content.txt` создаётся автоматически и вручную не редактируется.
6. Положите главное изображение в `cover.jpg`.
7. Добавьте планировки:
   - `planning/plan-before.jpg`
   - `planning/plan-after.jpg`
8. Создайте блоки галереи внутри папки `gallery`.

Формат названия папки галереи:

```text
01-студія__Studio
02-спальня__Bedroom
03-дитяча кімната__Children's room
```

До `__` указывается украинское название, после `__` — английское.

Внутри каждой папки галереи:

```text
preview/  изображения для сетки страницы
full/     полноразмерные изображения для просмотра
```

Файлы в `preview` и `full` сопоставляются по последнему номеру в имени.
Количество папок галереи и изображений внутри них может быть любым.

Подробные правила заполнения текста находятся в `CONTENT-GUIDE.md`.
`project.auto.json` содержит только технические настройки и обычно не требует
ручного изменения, кроме адресов создаваемых страниц для нового проекта.

Сначала проверьте исходный текст:

```powershell
node scripts/prepare-project-content.js --project project-folder --check
```

Затем создайте служебный контент и страницы:

```powershell
node scripts/generate-project-page.js --project project-folder
```

Категории, показ на главной и весь видимый текст страницы и карточки берутся
из автоматически созданного `project-content.txt`. Подробные правила находятся
в `CONTENT-GUIDE.md`.
