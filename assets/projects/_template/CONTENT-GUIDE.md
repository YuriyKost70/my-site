# Заполнение текста карточки проекта

Весь изменяемый текст находится в `project.auto.json`. HTML и CSS редактировать
для нового проекта не нужно: генератор всегда использует одинаковую структуру,
типографику, отступы и декоративные элементы.

## Блок Hero

```json
"hero": {
  "left": {
    "uk": "СУЧАСНА\nКВАРТИРА",
    "en": "MODERN\nAPARTMENT"
  },
  "right": {
    "uk": "КОНСУЛЬТАЦІЯ ДО КУПІВЛІ\nТА ПРОСТОРОВЕ ПЛАНУВАННЯ",
    "en": "PRE-PURCHASE CONSULTATION\nAND SPACE PLANNING"
  },
  "imageAlt": {
    "uk": "Сучасна квартира — головна візуалізація",
    "en": "Modern apartment — main visualization"
  }
}
```

- `left` — назва проєкту в лівій частині Hero.
- `right` — коротка характеристика проєкту в правій частині.
- `\n` задає контрольований перенос рядка.
- Кожна частина Hero може мати один або два рядки, але не більше.
- Зображення Hero завжди береться зі шляху `paths.cover`.

## Інформаційний блок

```json
"info": {
  "kicker": {
    "uk": "Про проєкт",
    "en": "About the project"
  },
  "heading": {
    "uk": "Квартира для молодої сім’ї",
    "en": "Apartment for a young family"
  },
  "paragraphs": {
    "uk": [
      "Перший абзац опису.",
      "Другий абзац опису."
    ],
    "en": [
      "First description paragraph.",
      "Second description paragraph."
    ]
  },
  "meta": [
    {
      "label": { "uk": "Локація", "en": "Location" },
      "value": { "uk": "Україна", "en": "Ukraine" }
    },
    {
      "label": { "uk": "Площа", "en": "Area" },
      "value": { "uk": "93,18 м²", "en": "93.18 m²" }
    }
  ]
}
```

- `kicker` — маленький золотистий напис над заголовком.
- `heading` — головний заголовок опису.
- Кожен елемент `paragraphs` автоматично стає окремим абзацом.
- Кожен елемент `meta` автоматично стає окремим пунктом правої колонки.
- Кількість абзаців і пунктів `meta` може відрізнятися між проєктами.
- Якщо англійське поле порожнє, англійська сторінка тимчасово використовує
  український текст.

Генератор перевіряє обов’язкові українські поля, кількість рядків Hero та
наявність потрібних папок і файлів. При помилці сторінка не буде перезаписана,
а в консолі з’явиться точна назва проблемного поля.
